# Установка переносимого комплекта

## Что находится в репозитории

Комплект содержит профиль **Vault customs RUS**, включённые в нём моды Vault Customs и шаблон настройки MO2. Сохранения в комплект не входят.

**Для установки всей сборки этих файлов недостаточно.** В репозитории отсутствуют сторонние моды, Mod Organizer 2, игра и F4SE. Установщик Wabbajack пока недоступен. Приведённые ниже шаги предназначены для переноса комплекта в отдельно подготовленную установку со всеми зависимостями.

## Требования

- Fallout 4 **1.10.163** и необходимые для сборки дополнения.
- F4SE **0.6.23**.
- Отдельная переносимая установка Mod Organizer 2.
- Все сторонние моды и зависимости сборки.
- Python **3.10 или новее** для скрипта настройки путей.

## Подготовка папок

В примерах сборка расположена в `D:\VaultCustoms`. Замените этот путь своим.

1. Закройте игру и MO2.
2. Подготовьте отдельную переносимую установку MO2. В её корне должен находиться `ModOrganizer.exe`.
3. Разместите файлы игры и F4SE в подпапке `Stock Game Folder`. Проверьте наличие `Fallout4.exe` и `f4se_loader.exe` указанных выше версий.
4. Скопируйте папки `profiles` и `mods` из репозитория в папку MO2. При переносе поверх уже настроенной установки предварительно сохраните копии её профилей и настроек.
5. Установите сторонние зависимости сборки. Список названий доступен в [каталоге модов](mods.md), но он не заменяет установщик с точными версиями и вариантами установки.

Ожидаемая структура:

```text
D:\VaultCustoms\
  ModOrganizer.exe
  Stock Game Folder\
    Fallout4.exe
    f4se_loader.exe
  profiles\
    Vault customs RUS\
  mods\
```

## Настройка путей MO2

Скрипт предназначен для новой установки без `ModOrganizer.ini`. Если этот файл уже существует, скрипт остановится. Сохраните его резервную копию и настройте пути вручную либо используйте отдельную новую установку.

Откройте PowerShell в папке скачанного репозитория. Сначала проверьте пути:

```powershell
python scripts/configure_mo2.py --root 'D:\VaultCustoms' --check
```

Если проверка прошла, создайте конфигурацию:

```powershell
python scripts/configure_mo2.py --root 'D:\VaultCustoms'
```

Скрипт создаст `ModOrganizer.ini` и `portable.txt`, выберет профиль `Vault customs RUS` и добавит пункт запуска **Play Vault Customs**. Проверка `--check` подтверждает наличие основных файлов; версии игры, полный состав модов и работоспособность запуска она не проверяет.

## Первый запуск

1. Откройте MO2 из папки сборки и выберите `Vault customs RUS`.
2. Проверьте пути к игре, отсутствие пропущенных мастер-файлов и включение необходимых модов. Сохраните поставляемый порядок модов и плагинов.
3. Настройте разрешение и графику под свой компьютер. Профиль использует собственные INI в `profiles/Vault customs RUS`; изменение INI в папке «Документы» не меняет настройки этого профиля.
4. Выберите **Play Vault Customs** и запустите игру через MO2.
5. Для первой проверки начните новую игру, дождитесь инициализации модов, проверьте русские тексты и сохранение с последующей загрузкой.

Для обновления и дополнительных настроек смотрите [основную инструкцию](../README.md).
