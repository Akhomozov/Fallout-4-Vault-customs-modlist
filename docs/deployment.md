# Переносимый комплект

## Что включено

Экспорт основного профиля `Vault customs RUS`: десять файлов профиля, включая порядок модов, порядок плагинов и игровые INI. В `mods/` находятся только включённые в этом профиле папки `Vault_customs*` и их рабочие ресурсы. Даже папка с суффиксом `_test` включается, если она активна в основном профиле; название не заменяет проверку состояния.

В `manifests/export.json` перечислены файлы, размеры, контрольные суммы исходников и экспортных копий, исключения и очистка метаданных. Это снимок экспорта, а не подтверждённый игровой релиз. Полное описание и каталог в `docs/` пока сохраняют свою прежнюю редакцию и не заменяют свежий manifest.

## Что исключено

Резервные копии, PDB, логи, сохранения, `meta.ini`, отчёты разработки, исходники Papyrus, папки `_original` и `optional`, отключённые Vault Customs. Исходники следует публиковать отдельным проверенным комплектом, а не копировать всю папку разработки.

Папки `optional` в установленном моде не являются активными ресурсами по стандартным игровым путям; их варианты в этот комплект не включены. Сторонние авторские уведомления и лицензии потребуется подготовить по происхождению ресурсов до публичного распространения: удалённый MO2 `meta.ini` не заменяется утверждением собственного авторства.

Сторонние моды, сама MO2, файлы игры, загрузчик F4SE, корневые библиотеки и пользовательский `overwrite` не копировались. Настройки внутри сторонних модов также ещё не экспортированы. Для полной воспроизводимости будущий Wabbajack должен закрепить источники, версии, варианты установки и наши изменения этих файлов; одного списка названий недостаточно.

## Очистка данных

В игровых INI абсолютный путь скриншотов заменён на `ScreenShot`. Игровые графические значения сохранены как снимок рабочего профиля; разрешение, производительность и совместимость апскейлера нужно настроить под новый компьютер.

В PEX очищены три служебных поля заголовка: путь исходника, имя пользователя и имя компьютера. Размеры полей и остальная часть файла сохранены. В DLL очищены диагностические пути сборки в ASCII и UTF-16, без изменения длины файла. Для каждой изменённой DLL проверено побайтовое совпадение всех исполняемых секций PE. Это не перекомпиляция и не игровой тест. Исходные файлы рабочей сборки не изменены.

В NIF встречаются исходные пути редактора Bethesda вида `g:\_F4\Scratch\Editor...`. Это метаданные ресурсов, а не путь пользователя сборки; они сохранены. Автоматическая проверка личных данных не является проверкой авторских прав и не гарантирует обнаружения произвольных секретов во всех возможных форматах.

## Подготовка MO2 на другом компьютере

1. Подготовьте отдельную переносимую установку MO2. Разместите проверенные Fallout 4 1.10.163 и F4SE 0.6.23 в её `Stock Game Folder`. Эти файлы в репозитории отсутствуют.
2. Разместите `profiles/` и `mods/` этого комплекта в папке MO2. Установите все сторонние зависимости соответствующего релиза. Пока Wabbajack не выпущен, этот шаг автоматически не выполняется.
3. Закройте MO2. Скрипт рассчитан на новую установку без существующего `ModOrganizer.ini`; существующий конфиг он не перезаписывает.
4. При наличии Python 3.10 или новее выполните из клона репозитория:

   ```powershell
   python scripts/configure_mo2.py --root 'D:\VaultCustoms' --check
   python scripts/configure_mo2.py --root 'D:\VaultCustoms'
   ```

5. Скрипт создаст локальные `ModOrganizer.ini` и `portable.txt`, укажет пути новой установки, выберет `Vault customs RUS` и добавит `Play Vault Customs` для запуска F4SE. Файл создаётся из минимального шаблона; настройки аккаунтов, история и инструменты разработки в него не переносятся.
6. В MO2 проверьте профиль, игровые пути, отсутствие пропущенных мастер-файлов и выбранное разрешение. Для первой проверки начните новую игру и проверьте сохранение с последующей загрузкой.

`--check` проверяет наличие файлов и пути, но не версии EXE, полноту модов или запуск игры. Созданные локальные пути исключены из Git через `.gitignore`. Синтаксис шаблона проверен офлайн; запуск MO2 с новым конфигом на другом компьютере ещё не проверялся.

## Проверка перед коммитом

```powershell
python scripts/verify_repository.py
git diff --check
git status --short
```

Проверяются контрольные суммы, лишние файлы, известные локальные идентификаторы, пути и сигнатуры ключей. Проверка читает также UTF-16 и распаковывает CWS SWF. Личные настройки MO2 не должны попадать в индекс Git. Не используйте `git add -f` для обхода исключений.

Повторный экспорт выполняется `python scripts/export_repository.py --source '<папка рабочей сборки>'` в свежем клоне без `mods/`. Это намеренное ограничение: старые файлы релиза не должны незаметно оставаться в новом экспорте. Путь источника не сохраняется в публичном manifest.

## Перед публичным релизом

Нужны проверка происхождения и условий распространения заимствованных мешей, анимаций, интерфейса, переводов, строк и скриптов; закрепление сторонних зависимостей; проверка чистой установки и запуска. Включение DLL и ESP в комплект означает наличие реализации, а не подтверждение всех её функций в игре.
