# Редакционные основания и ограничения проверки

Эти заметки предназначены для сопровождения сборки. Не являются инструкцией игроку.

docs/description.md: Редакция описания 0.2.4 от 29 октября 2026 года. Черновик по снимку редакции 0.2.0 профиля `Vault customs RUS`.

docs/mods.md: Для ресурсов внутри общих архивов указано место упаковки. Экспериментальные разработки отмечены в соответствующих строках. Назначение остальных позиций описано по установленным файлам, локальным метаданным и документации; включение позиции не означает, что все функции исходного мода активны.

docs/mods.md: - **Vault_customs_enemy_level_floor** — Экспериментально задаёт нижний порог уровня врагов относительно игрока; проверка в игре ещё не завершена.

docs/mods.md: - **Not Just for Christmas - Companion Perks Apply Only While Following** — Ограничивает действие бонусов спутников временем совместного путешествия; взаимодействие с другими перками требует проверки.

docs/mods.md: - **Vault_customs_wall_weapon_racks** — Добавляет настенные стойки на четыре пистолета или три длинноствольных оружия; игровая проверка ожидается.

docs/mods.md: - **Vault_customs_recent_items** — Переключает сортировку вещей игрока по получению: старые, новые, прежний порядок; игровая проверка последней версии ожидается.

docs/mods.md: - **Vault_customs_backpack_stack** — Экспериментально позволяет совмещать несколько разных рюкзаков; текущая версия требует проверки в игре.

## Прежние организационные формулировки README

Описание и каталог относятся к редакции 0.2.4 от 29 октября 2026 года. Описание подготовлено по снимку 0.2.0; перед выпуском установщика состав и настройки будут сверены заново. Номер редакции текста не обозначает версию установщика.

- Собственная копия Fallout 4 и необходимые дополнения. Точный комплект DLC и Creation Club будет указан для первого установочного релиза.
- Целевая версия игрового исполняемого файла: **Fallout 4 1.10.163**, загрузчик **F4SE 0.6.23**. Текущая рабочая сборка использует отдельный каталог `Stock Game Folder`.
- Mod Organizer 2 с профилем `Vault customs RUS` и отдельными INI профиля.
- SSD для установленной сборки. Требования к свободному месту и оборудованию будут опубликованы после замера установочного комплекта и проверки производительности.

Указание «последняя версия Steam» из инструкции исходного Life in the Ruins не определяет версию запускаемой игры Vault Customs. Процедура подготовки файлов игры будет закреплена вместе с установщиком.

Это порядок подготовки будущего установочного релиза. Сейчас он не заменяет отсутствующий пакет Wabbajack.

1. Проверить требования выбранного релиза: версию игры, дополнения, свободное место и совместимость сохранений.
2. Подготовить чистую установленную игру и выполнить её первоначальный запуск, если это требуется инструкцией релиза.
3. Выбрать отдельный короткий путь для сборки, например `D:\VaultCustoms`, и отдельную папку скачанных архивов. Не устанавливать сборку поверх другой сборки или непосредственно в каталог Steam-игры.
4. Скачать Wabbajack и установочный файл Vault Customs из будущего раздела Releases. Пока такого файла нет, продолжить автоматическую установку нельзя.
5. Установить сборку через Wabbajack. Сторонние моды должны загружаться из указанных источников; файлы Vault Customs — из закреплённого комплекта соответствующего релиза.
6. Открыть MO2 из установленной сборки, выбрать `Vault customs RUS`, проверить путь к `Stock Game Folder` и запись запуска F4SE.
7. Настроить разрешение и доступные графические параметры по инструкции релиза, затем выполнить первый запуск.

1. Запустите MO2 из папки сборки и выберите основной профиль.
2. Запустите F4SE, настроенный на `Stock Game Folder`. Запуск обычного Fallout 4 из Steam не запускает профиль MO2.
3. Для первой проверки начните новую игру. Дождитесь завершения стартовых уведомлений и инициализации модов.
4. Порядок применения MCM-пресетов будет указан после проверки релиза. Не загружайте настройки исходного Life in the Ruins поверх Vault Customs без отдельного указания.
5. Проверьте русские тексты, интерфейс, управление и сохранение с последующей загрузкой.

Сторонние моды принадлежат своим авторам и распространяются на их условиях. Среди Vault Customs есть собственные разработки и интеграции сторонних материалов; название папки не означает авторство всех включённых ресурсов. Права и источники распространяемых файлов должны быть проверены до включения в публичный релиз.
