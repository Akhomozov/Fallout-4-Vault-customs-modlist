# Сопровождение и разработка

Пользовательские документы находятся в корневом `README.md` и `docs/`. Эта папка предназначена для авторов и сопровождающих сборки.

## Содержимое

- `manifests/export.json` — состав экспорта, исходные и экспортные SHA-256, исключённые файлы и очистка метаданных.
- `manifests/privacy-check.json` — результат автоматической проверки комплекта.
- `scripts/export_repository.py` — экспорт профиля и активных Vault Customs из рабочей сборки.
- `scripts/verify_repository.py` — проверка состава, контрольных сумм и известных сигнатур личных данных.
- `notes/documentation-audit.md` — редакционные основания и ограничения проверки, убранные из пользовательских документов.
- `notes/main-menu-patch.txt` — техническая инструкция патча MainMenu.swf с указанием исходного MCM Booster.

Пользовательский скрипт настройки MO2 остаётся в `scripts/configure_mo2.py`.

## Команды сопровождения

Запускать из корня репозитория:

```powershell
python dev/scripts/verify_repository.py
git diff --check
git status --short
```

Экспорт в свежий клон без папки `mods/`:

```powershell
python dev/scripts/export_repository.py --source '<папка рабочей сборки>'
```

После экспорта повторить проверку. Сохранять точные байты модов и файлов профиля: правила `.gitattributes` отключают преобразование окончаний строк в этих папках. Сверять не только рабочие файлы, но и Git blobs перед публикацией.

## Ограничения и задачи

- Проверить происхождение, лицензии и авторские уведомления заимствованных ресурсов перед установочным релизом. Каталоги Vault Customs содержат как свои разработки, так и интеграции; название не означает авторство всех ресурсов. Эта проверка не завершена.
- Зафиксировать версии, источники и варианты установки сторонних модов, их локальные изменения, настройки и корневые библиотеки.
- Собрать Wabbajack и проверить полную чистую установку. Имеющиеся профиль и Vault Customs не воспроизводят всю сборку.
- Проверить переносимый конфиг настоящим запуском MO2; офлайн проверены подстановка путей, пробелы и Unicode.
- Проверить функции модов в игре. Чистые хеши и сохранность исполняемых секций не заменяют игровой тест.
- Сверить каталог и полное описание редакции 0.2.4 со свежим составом. Их базовый текст подготовлен по более раннему снимку, а не по текущему экспорту.
- Подтвердить комплект DLC/Creation Club, требования к памяти и месту, настройки MCM и совместимость сохранений для установочного релиза.

Приватные рабочие заметки `docs/*.local.md` остаются только на компьютере и исключены через `.gitignore`. Не копировать их в публичные документы. Перенос заметок в `dev/` допустим только после проверки личных данных; `dev/` публична наравне с остальным репозиторием.
